# Evidence kit for the team (templates, not product features)

These files are for the people building and selling SolsArch. They contain no results and no customer numbers; every cell is empty until real evidence exists.

| File | Use |
| :--- | :--- |
| design-partner-programme.md | A four-week engagement with a small team: what they get, what they give, consent to an anonymised case study |
| design-partner-tracker.csv | Weekly count of the five numbers that matter: partners, assisted deployments, paid conversions, case studies, recommenders |
| unit-economics-worksheet.md | Cost per analysis from measured run time (`benchmark.py run`) and your own compute price |
| weekly-review.md | The four questions to answer every Friday |

Rule: a number goes in only with a link to where it came from.
