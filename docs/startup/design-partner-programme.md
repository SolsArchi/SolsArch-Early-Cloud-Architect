# Design partner programme (template)

**Length:** four weeks. **Partners:** teams that deploy to a cloud at least monthly and will give weekly feedback.

| Week | We do | They do |
| :--- | :--- | :--- |
| 1 | Run SolsArch on their repository and rules; review the report with them | Share a repository (or a copy) and their cloud standards |
| 2 | Fix what they found wrong; add their rules | Try the deploy guide or the generated code in a test account |
| 3 | Add the pull-request impact check to their pipeline | Use it on real changes |
| 4 | Measure: time saved (their estimate), blockers found, rules enforced | Say what they would pay for, or why not |

**What they get:** the zip, a pipeline check and direct support. **What we ask:** honest feedback and, only if they agree in writing, an anonymised case study.
**Never:** their code leaves their machine through SolsArch (it reads files locally); never ask for cloud credentials.
